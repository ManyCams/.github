# 🎥 ManyCam

ManyCam is a **virtual camera** and **live studio**. Build scenes from **layers**, apply effects, record the output, and select the virtual cam inside meetings or streams. **Presets** store whole scenes.

## ✨ Key Features

- 📷 **Virtual camera** output
- 🧩 **Scene layers** with sources
- 🎨 **Effects and filters**
- ⏺️ **Recording** of the scene
- 💾 **Scene presets**
- 🖥️ **Screen and window capture**
- 🎚️ **Picture-in-picture**
- 🔤 **Text and overlay elements**

## 🚀 Why Choose ManyCam?

Layers turn a flat camera feed into a composed scene: webcam, screen, text, and picture-in-picture in one stack. The virtual cam then carries that scene into any app that accepts a camera.

Presets bring a whole scene back in one click.

## 🎮 Why Use It?

- **Compose scenes** from layers
- **Show a screen** beside the camera
- **Record without a second app**
- **Reuse presets** per meeting type
- **Keep effects applied** live

## 🧩 Quick Start

1. Install ManyCam and open the studio.
2. Add a camera and screen source.
3. Arrange layers and add text.
4. Select ManyCam as the camera in your app.
5. Save the scene as a preset.
